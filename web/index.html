Verwaltete Sessions

Hier erscheinen Starts über claude-account run und den T3-Launcher. Bereits laufende, anders gestartete T3-Threads werden nicht nachträglich übernommen.

Terminal & T3 einrichten

Für jeden Account einmal einen eigenen offiziellen Claude-Login anlegen. Bereits vorhandene native Konfigurationen können stattdessen mit bind angebunden werden.

claude-account session-login privat
claude-account session-login arbeit
claude-account share-setup privat
claude-account share-setup arbeit

claude-account run privat
claude-account run arbeit
claude-account map privat /home/du/projekte/app

In T3 unter Providers als Claude-Binary ~/.cargo/bin/claude-account-t3 auswählen und das Feld CLAUDE_CONFIG_DIR leer lassen. Der Launcher wählt den Account je Session. Für einen Wechsel mit bestehendem Verlauf müssen die beteiligten Accounts den Projektverlauf teilen.

Die Zugangsdaten bleiben in Claudes nativen Konfigurationsverzeichnissen. Diese Seite liefert weder Tokens noch Passwörter aus.

Nur lokale Verwaltung. Kein Konto wird erstellt, kein Limit verändert, keine laufende Antwort für einen Account-Wechsel abgebrochen.
